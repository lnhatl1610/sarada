# UI/UX Principles

- Storefront is mobile-first; admin is desktop-first but remains usable on tablet.
- Use a minimal neutral palette, dark readable text, fine dividers, flat surfaces, restrained accents, clear hierarchy, generous spacing, and image-led product presentation.
- Meet WCAG 2.1 AA intent: visible keyboard focus, semantic headings, labeled controls, keyboard operation, non-color status cues, and 4.5:1 text contrast.
- Every async view needs loading, empty, error, and success states. Explain validation errors next to the relevant field in Vietnamese.
- Confirm destructive actions and stock adjustments. Use toast for low-risk feedback, not as the only place for critical errors.
- Prefer modest motion; respect `prefers-reduced-motion`.
