# Requirements Index

Requirements use immutable IDs: `FR-<MODULE>-NNN`, `NFR-<TYPE>-NNN`, and `BR-<MODULE>-NNN`. Modules: AUTH, CAT, CART, CHK, ORD, INV, CPN, CUS, ADM, REV, CMS, MKT. Types: PERF, SEC, AVAIL, A11Y, SEO, OBS, MAINT.

Each entry has a normative description using “must”, MoSCoW priority, verifiable acceptance criteria, source, linked spec, and status. Never reuse an ID. When behavior changes, update the requirement before the spec and implementation; update traceability at the same time.

See `vision-scope.md`, `functional-requirements.md`, `non-functional-requirements.md`, `business-rules.md`, `user-stories.md`, `glossary.md`, `traceability.md`, and `open-questions.md`.
