# User Stories

## Shopper
- As a guest, I want to browse/filter products so I can find apparel by category, price, size, and color.
- As a shopper, I want to select an available variant, so I can buy the correct size and color.
- As a guest, I want to keep a cart and checkout with COD, so I can order without creating an account.
- As a shopper, I want to check shipping fees and configured delivery times for my destination on a product page, so I can compare delivery choices before checkout.
- As a customer, I want my guest cart merged after login, so I do not lose selected items.
- As a subscribed customer, I want a reminder when I leave items in my cart, so I can return to the current cart and review live stock and prices.
- As a customer, I want to receive an email when a watched product drops below its current price or a sold-out size returns, so I can decide when to buy.
- As a customer, I want to track an order with its code and contact details, so I can see delivery progress.
- As a verified buyer, I want to submit a review with photos or a short video after delivery, so other shoppers can learn from my experience.
- As a shopper, I want to read answered product questions or ask the store about a product, so I can make an informed purchase.
- As a shopper, I want to browse and search store FAQs by topic, so I can quickly find answers about ordering, shipping, payment, and returns.
- As a content editor, I want to publish and organize FAQ entries, so shoppers receive current guidance from the store.

## Staff
- As catalog staff, I want to create products and variant stock in one workflow, so shoppers see accurate availability.
- As order staff, I want to advance orders only through allowed states, so fulfillment history stays reliable.
- As inventory staff, I want every adjustment to include a reason, so stock changes are auditable.
- As a manager, I want dashboard and report summaries, so I can monitor sales and stock.
- As a super admin, I want role/permission management, so staff can access only assigned operations.

Acceptance scenarios are maintained in the matching `specs/*/spec.md`; IDs are listed in `traceability.md`.
