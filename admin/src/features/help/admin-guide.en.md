# Admin area guide

## Products and inventory

### Create and update a product
Open Products to search by name or SKU. Use Add product to enter details, variants, prices, and images; you can save a product as a draft before publishing it. Adjust stock through Stock adjustments so the staff member and reason are recorded.

### Import stock from CSV
Download the CSV template from the Import page, keep the SKU values unchanged, and enter quantities. Review the preview before confirming. If any rows are rejected, download the error file to see the reason for each row.

## Orders and customers

### Process a COD order
Open an order to review the address captured when it was placed, its products, and its status history. Update it through the allowed steps; internal notes are not sent to the customer. Confirm collection of payment after a successful handoff.

### Refund or cancel an order
Use the refund action only after payment has been recorded. The system stores the amount, reason, and staff member. Cancelling an order checks its status and restores inventory according to the order rules.

## Promotions and content

### Create a coupon
Choose the discount type, value, active period, minimum order, and usage limit. Review the rule preview before activating the coupon. The server always recalculates the final total.

### Update a banner or content page
Upload an image to the media library, enter alternative text, and set a display period if needed. Use draft status to review content before publishing.

## Reports and operations

### Read a report
Choose a date range and suitable filters. Monetary values are shown in VND. Cancelled and unpaid orders are identified in each report.

### Check system health
The System health page shows database, queue, scheduler, email, and storage status.

## Account

### Protect your admin account
Enable two-factor authentication, review recent login history and revoke unfamiliar sessions. Never send passwords or recovery codes through support messages.
